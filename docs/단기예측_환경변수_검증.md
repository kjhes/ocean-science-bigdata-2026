# 단기(1일 뒤) 수온 예측: 환경변수 추가 검증

> 2026-09-16. 1차 멘토링 지적 ⑤("기온·일사량·강수량·해풍을 추가하라")에 대한 실험.
> 팀원이 확보한 기상청 ASOS 시간자료(완도170·여수168·통영162·남해295, 2021~2025)를
> 사용. 강수량·일사량은 결측 문제로 보류하고(아래 5절), 우선 **기온·풍속·풍향**만 사용.

> ## ⚠️ 미확인 전제 (2026-09-16 추가) — 아래 결과는 이게 확인되기 전까지 조건부다
>
> 기상 데이터(기상청 ASOS, 육상 관측소)와 수온 데이터(국립수산과학원, 해양 관측소)는
> **서로 다른 기관의 서로 다른 물리적 지점**이다. 두 관측소가 실제로 얼마나 가까운지
> (같은 항구 근처인지, 몇 km 이상 떨어져 있는지) **아직 확인하지 못했다.**
>
> 만약 두 관측소가 멀리 떨어져 있다면, "육상 기온이 그 지역 수온에 영향을 준다"는
> 이 실험 전체의 전제가 약해질 수 있다. 검색으로 좌표를 찾으려 했으나 공식
> 사이트가 로그인 후 다운로드 버튼을 눌러야 하는 구조라 확보하지 못했다.
> **사람이 직접 확인해야 하는 항목**(예: 네이버지도에서 "여수기상대"와 "여수 신월
> 해양관측소"를 검색해 거리 비교)이며, 확인 전까지 아래 성능 수치는
> "위치가 비슷하다는 가정 하의 잠정 결과"로 취급한다.

## 1. 문제 정의

어제(t-1)까지의 정보로 오늘(t)의 수온을 예측한다. 같은 날 기온을 입력으로 쓰지
않는다 (운영 시점엔 오늘 기온도 다 관측되지 않았을 수 있어 보수적으로 lag1만 사용
— 데이터 누수 방지).

- **학습**: 2021~2023년 (3년)
- **검증**: 2024~2025년 (2년, 아껴둔 데이터) — **2024년 9월 이상값 사례가 검증
  기간에 포함**되어 있어, 환경변수 추가가 실제로 그 사례를 더 잘 잡는지 직접 확인 가능
- **입력변수**: 수온 lag1/lag2/lag3, 기온평균·최저·최고 lag1, 풍속평균 lag1,
  계절(sin/cos of day-of-year)
- **비교 모델**: 지속성(persistence, 어제값=오늘 예측) / 평년값(climatology) /
  선형회귀 / 랜덤포레스트

## 4. 환경변수(기온·풍속)가 실제로 기여하는가 — Ablation

지속성이 이미 강력해서, 선형회귀의 개선이 "환경변수 덕분"인지 "lag를 여러 개
넣어서"인지 구분이 필요했다. lag만 쓴 모델과 lag+환경변수 모델을 비교:

| 지역 | lag만 RMSE | lag+환경변수 RMSE | 개선율 |
|---|---:|---:|---:|
| 완도 | 0.323 | 0.297 | **8.1%** |
| 여수 | 0.308 | 0.283 | **8.1%** |
| 통영 | 0.279 | 0.277 | 0.7% |
| 남해군 | 0.385 | 0.378 | 1.8% |

**환경변수의 기여가 지역에 따라 다르다.** 완도·여수(개방 해안, 계절 진폭 큰 지역 —
`docs/연구_과정_서사.md` 4지역 비교 참고)에서는 기온·풍속이 유의미하게 도움되지만,
통영·남해군(폐쇄적 내만, 열관성 큰 지역)에서는 거의 영향이 없다. 이는 앞서 확인한
지역별 해양 특성 차이와 일관된 결과다 — 내만은 수온이 대기 조건보다 자체 열관성에
더 좌우된다는 뜻으로 해석할 수 있다.

## 4-1. 예측값을 경보 로직에 연결 — "모델이 실제로 제때 경보를 냈을까?"

`src/models/forecast_alert.py`: 선형회귀 예측치를 `alert.py`의 공식 경보 기준에
그대로 대입해, 검증기간(2024~2025) 동안 실제 관측 기준 경보와 예측 기준 경보가
얼마나 일치하는지 비교했다. 평년값 기준선은 양쪽에 동일한 것(실측 전체 기간으로
계산)을 사용해 공정하게 비교.

| 지역 | 전체 일치율 | 실제 경보/주의보였던 날 중 예측도 잡은 비율(재현율) |
|---|---:|---:|
| 완도 | 94.0% | 76.1% |
| 여수 | 97.3% | 89.8% |
| 통영 | 93.4% | 79.7% |
| 남해군 | 96.4% | 86.7% |

전체 일치율은 대부분 "평시"라 높게 나오는 게 당연하므로, **재현율(실제 위험한 날을
놓치지 않는 비율)이 더 중요한 지표**다. 76~90% 수준 — 나쁘지 않지만 10~24%는 여전히
놓친다는 뜻이라, 실제 서비스라면 이 부분이 한계로 명시되어야 한다.

**2024년 9월(이상값 구간) 상세**: 여수·완도·통영은 예측 경보일수가 실제와 거의
일치(예: 여수 22일 실제 vs 22일 예측). **남해군만 실제 경보 20일 중 예측은 11일만
경보로 잡고 나머지는 주의보로 낮춰 잡음** — 4-절의 ablation에서 남해군이 환경변수
개선폭이 가장 작았던(1.8%) 것과 일관된 결과. 남해군 모델이 현재 가장 약한 지점이다.

결과: `reports/forecast_alert/`.

## 4-2. 강수량 추가 — 의미 확정 후 재실험

공란의 의미를 세 가지 독립적인 근거로 교차검증했다:
1. 월별 결측률에 뚜렷한 계절 패턴 확인 — 겨울 95~97% vs 장마·태풍철인 여름 84~87%
2. 실제 기록된 사건으로 대조: 2023년 7월 전남 집중호우(완도 37.6mm·여수 85.8mm
   기록), 2022년 태풍 힌남노 상륙(상륙지 부산과 가장 가까운 남해가 최대 시간당
   60.2mm·합계 299.8mm로 가장 크게 기록 - 지리적으로 정합적)
3. 기상청 공식 「지상(종관,ASOS) 일자료 조회서비스 Open API 활용가이드」의 응답
   예제를 확인 - 무강수일을 공란이 아니라 **명시적으로 "0.0"**으로 표기함
   (`<sumRn>0.0</sumRn>`). 이 문서는 일자료(하루 집계) API 문서라 우리가 쓰는
   시간자료(매시간) API와 동일 문서는 아니지만, 같은 기관·같은 설계 철학을 보여줌

세 근거가 모두 같은 방향(공란=무강수)을 가리켜 **결측 = 무강수(0mm)로 확정**하고
사용자 확인을 받았다. `load_weather.py`에서 0으로 채워 `rain_sum`(일별 강수량 합)
집계, `rain_sum_lag1`을 선형회귀에 추가.

**결과: 성능에 거의 변화 없음.**

| 지역 | 강수량 추가 전 RMSE | 추가 후 RMSE |
|---|---:|---:|
| 완도 | 0.2965 | 0.2965 |
| 여수 | 0.2827 | 0.2828 |
| 통영 | 0.2771 | 0.2768 |
| 남해군 | 0.3781 | 0.3782 |

데이터 신뢰도를 확보한 뒤 넣었는데도 도움이 안 됐다는 것 자체가 유효한 결과다.
1일 뒤 수온에 대한 강수량의 직접적 영향은 이 시차(전일 하루치 합)로는 잡히지
않는 것으로 보인다 (담수 유입·성층 형성 등은 더 긴 시차나 누적 효과일 가능성).

## 4-3. 일사량 — 장비 설치 시점 확인 후 테스트, 역시 효과 미미

일사량 결측을 정밀 확인한 결과, "결측"이 아니라 **관측 장비가 해당 날짜부터
설치된 것**으로 보인다 (날짜를 기점으로 전혀 없던 값이 정상 패턴으로 전환):
- 여수: 2021년부터 계속 있음 (낮 08~18시만, 야간 결측은 정상)
- 완도: 2024-03-27부터 시작
- 통영: 2023-01-17부터 시작
- 남해: 5년 내내 전무

학습기간(2021~2023)에 데이터가 있는 지역은 **여수뿐**이라 여수만 테스트 가능.
위성 추정치 같은 대체 자료를 구하는 방법도 있으나, 먼저 여수로 효과를 확인한
뒤 투자할지 결정하기로 함.

**결과: RMSE 개선율 0.6%** — 강수량과 마찬가지로 사실상 무의미.
→ **일사량은 완전히 보류.** 대체 자료(위성 추정치 등)를 구하는 추가 작업 안 함.

## 5. 최종 확정된 입력변수

기온(평균·최저·최고)·풍속·강수량·수온 자체(lag)·계절(sin/cos). 강수량·일사량
모두 "데이터를 확실히 만든 뒤 넣어봤지만 도움 안 됨"을 확인했고, 핵심은
**수온 자기 자신의 최근 값(지속성) + 기온·풍속**이라는 결론이 여러 차례의
ablation으로 일관되게 나왔다.

## 7. 급등일 과소예측 문제 발견 및 대응 (2026-09-16)

### 7-1. 문제: 모델이 갑작스러운 수온 상승을 체계적으로 못 따라감

전일대비 실제 변화량과 예측잔차(실제-예측)의 상관계수를 계산하면 완도~남해군
전부 **0.74~0.97**로 매우 높음 — 급등하는 날일수록 과소예측이 커진다는 뜻.
전체 평균잔차는 0에 가까움(편향 없음)이지만, 상승일만 골라보면 평균
+0.16~0.29℃ 과소예측, 하락일은 반대로 과대예측.

**이게 모델 종류의 문제인지 확인**: XGBoost로도 재현됨(급등일 상관계수
0.50~0.64, RMSE는 선형회귀보다 오히려 나쁨: 완도 0.358 vs 0.297). 랜덤포레스트도
기존에 선형회귀보다 못했던 전례와 일관. → **회귀 목적함수(평균제곱오차 최소화)
자체의 성질이자 "어제까지 정보만 쓴다"는 정보 구조의 한계**이지, 모델 선택으로
해결될 문제가 아님. 어제·그제·그끄제 수온의 선형조합(추세항)을 명시적으로
추가해도 효과 0 — 이미 lag1~3 안에 그 정보가 다 있어서 새 정보가 아니었음
(수학적으로 당연한 결과, 실제로 소수점까지 동일하게 재현해서 확인).

### 7-2. ROMS 관련 세 가지 시도 — 전부 현재 단계에서는 불가

1. **ROMS 수치예측모델 OpenAPI** (data.go.kr): 실제 신청해서 인증키 발급
   받고 호출까지 확인. 그런데 응답의 `predcDt`가 **호출한 "오늘" 기준으로만
   시작**(과거 조회 불가, 사용제약사항에도 "현재 일자 기준 8일간 예측정보
   제공"이라고 명시됨) → 2021~2023년 학습 데이터에 ROMS 값을 못 넣음
2. **ROMS 계산식 직접 실행**: ROMS는 단일 수식이 아니라 3차원 해수유동
   편미분방정식을 격자별로 매시간 푸는 수치모델. 초기장·해저지형·대기강제력·
   경계조건·슈퍼컴급 연산이 다 필요해 13일 안에 재현 불가능
3. **국립해양조사원 해양재분석자료**(바다누리): 과거를 재현한 진짜 역사
   데이터라 구조적으로는 적합했으나, 언론 확인 결과 제공 기간이
   **2001~2020년**뿐 — 우리 학습기간(2021~)과 안 겹침

→ ROMS는 실시간 이후 비교용 벤치마크로만 활용(동해 냉수대 시스템 3일예측
RMSE 0.73℃ 대비 우리 1일예측 RMSE 0.26~0.36℃가 더 낮음), 모델 통합은 보류.

### 7-3. 채택: 당일 새벽 기온·풍속 + 벌크 열플럭스 공식

ROMS 대신, "오늘 날씨가 오늘 수온에 영향을 준다"는 가설을 우리가 이미 가진
ASOS 데이터로 직접 검증. 기존엔 데이터 누수를 우려해 기온·풍속도 전부
lag1(어제)만 썼는데, **당일 06시 이전 관측치**는 그 시각에 실제로 경보를
낸다고 가정해도 누수가 아님 — 이걸 피처로 추가.

여기에 해양학 벌크 열플럭스 공식(`Q = ρ·c_p·C_H·U·(T_air-T_sea)`, 풍속×
기온-수온차)의 구조를 차용해 `heatflux_proxy = 풍속(새벽) × (기온(새벽) -
수온lag1)` 상호작용항도 추가. 물리상수(밀도·비열·전달계수)는 정확히 대입하지
않고 구조(곱셈 형태)만 가져와 회귀가 스케일을 직접 학습하게 함 — "물리 법칙을
그대로 계산"이 아니라 "검증된 물리적 구조를 피처로 차용"임을 명확히 함.

**결과 (2021~2023 학습 → 2024~2025 검증, 공통 평가일 기준 RMSE)**:

| 지역 | 기존(어제 날씨만) | +당일새벽 선형 | +열플럭스 상호작용항 | 총 개선율 |
|---|---:|---:|---:|---:|
| 완도 | 0.2965 | 0.2679 | **0.2643** | 10.9% |
| 여수 | 0.2828 | 0.2566 | **0.2523** | 10.8% |
| 통영 | 0.2768 | 0.2715 | **0.2699** | 2.5% |
| 남해군 | 0.3782 | 0.3684 | **0.3644** | 3.6% |

2024년 9월(이상값 구간)도 전 지역 개선(13~17%). 완도·여수(개방 해안)는 뚜렷하게,
통영·남해군(폐쇄 내만)은 약하게 — 기존 "내만은 열관성 지배적" 해석과 일관.

### 7-4. 부작용 검증 (채택 전 확인한 것)

- **날짜별로는 37~50%가 오히려 나빠짐** — 평균은 개선되지만 모든 날이 좋아진
  건 아님(좋아지는 날의 개선폭 > 나빠지는 날의 악화폭이라 순이득)
- **월별로 보면 남해군 2~3월(+8.8~12.7%), 통영 12월(+11.9%)만 저하**, 나머지
  달은 대부분 개선. 처음엔 "겨울에 몰려서 나빠진다"고 추정했으나 월별로
  체계적으로 확인하니 틀린 추정이었음(여름 평균 -5.15%, 겨울 평균 -4.83%로
  둘 다 순개선)
- **남해군 5~8월은 heatflux_proxy의 단변량 상관관계 부호가 반대**(폐쇄내만
  특성상 바람이 열교환보다 혼합/용승을 통한 냉각으로 더 크게 작용하는 것으로
  추정). 그런데 실제로 heatflux_proxy를 빼고 재테스트하니 **다변량 회귀
  안에서는 그래도 도움이 됨**(6~8월 RMSE: 어제날씨만 0.627 → 당일선형 0.608 →
  +heatflux 0.601) — 단변량 상관관계와 다변량 기여도가 다를 수 있다는 걸
  직접 확인. → heatflux_proxy는 4개 지역 전부 유지, 남해군 2~3월·통영 12월
  저하는 한계로 문서화(부호반전이 아니라 그 시기엔 변수 설명력 자체가 약함)
- 상승일 편향은 완전히 없어지지 않음(특히 완도는 거의 그대로) — "급등을
  완벽히 잡는다"가 아니라 "어제까지 정보만 쓸 때보다 낫다" 정도로 서술할 것
- 다중공선성(기온·풍속과 그 상호작용항을 동시에 넣음) — 개별 계수 해석은
  불안정해질 수 있으나 예측 정확도(RMSE) 자체에는 문제 없음을 확인

### 7-5. KHOA 조위관측소 실측자료 — 발견했으나 미완성

바다누리 해양정보서비스에서 완도 조위관측소(위경도 명시, 수온·기온·풍속을
한 지점에서 동시 관측) 자료를 확인. 좌표가 정확히 나와 있어 "기상관측소-
수온관측소 거리 불확실" 문제를 해소할 실마리가 될 수 있음.

**단, 기존 NIFS 완도 군외 수온 데이터와 다른 지점으로 확인됨**(2021-01-01
일평균 9.52℃ vs 기존 6.5℃, 약 3℃ 차이) — 타겟 대체는 불가, 추가 입력변수
후보로만 검토 가능. 현재 3개월 샘플만 확보(`data/external/khoa_station/`),
전체기간(2021~2025)·4개 지역 전부 미확보 — **다음 단계로 남김**.
