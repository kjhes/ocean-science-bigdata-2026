> 1차 멘토링(09-10) 이후 실제로 구현·검증한 내용을 발표 순서대로 정리한 문서.
> 각 섹션 끝의 링크로 원본 데이터·코드까지 바로 확인 가능. 발표 스토리라인은
> [`docs/연구_과정_서사.md`](연구_과정_서사.md) 참고, 이 문서는 "지금 뭘 보여줄 것인가"에 집중한다.

## 0. 한 줄 요약 (엘리베이터 피치)

> "장기 수온 예측은 국내 어떤 모델로도 안 된다"는 1차 멘토링 지적을 받아들여 **단기(1일) 예측 +
> 고수온 경보**로 전환했다. 기상 실측값을 더한 선형회귀 모델로 RMSE 0.25~0.36℃를 냈고, 국립수산과학원
> 공식 경보 기준에 대입해 재현율 78~90%를 확인했다. **다만 원래 목표였던 "어종 추천"은 양식방식별
> 위험도 수치가 없어서 아직 못 붙였다** — 오늘 가장 먼저 여쭤볼 부분.

---

## 1. 여정 요약 (5장짜리로 말한다면)

1. **초기 가설**: 5년 데이터로 수온 상승 추세를 예측해 어종을 추천하자 → 평년값/조화회귀 모델로 2025년
   검증, RMSE ~1.5℃까지는 괜찮았다.
2. **문제 발견**: 그런데 고수온 피해가 실제 발생한 **2024년만 크게 틀렸다.** 원인을 4각도로 분해하니
   "정점이 8월에서 9월로 밀리고 안 내려온 것"이었다 (`docs/2024_이상값_분석.md`).
3. **근본 원인**: 평년값 모델은 "같은 지역·같은 시기면 다른 해도 환경이 비슷하다"는 전제 위에 있었는데,
   이 전제가 틀렸다는 걸 데이터로 반증했다. **데이터가 5년이라 안 된 게 아니라 20년이어도 안 됐다**
   (`docs/평년값_전제_검증.md`).
4. **1차 멘토링 전환**: 장기 예측 포기 → 단기(1~7일) 예측 + 고수온 경보 앱. 입력을 "날짜"에서
   "실측 환경변수"로 바꿈 (`docs/멘토링_1차.md`).
5. **지금까지 구현**: 기상 실측값 결합 선형회귀 모델 + 공식 경보기준 연결까지 완료. 성능은 아래 2절.

## 2. 핵심 성과 (수치로 보여줄 것)

### 예측 성능 — [reports/short_term_forecast/metrics.csv](../reports/short_term_forecast/metrics.csv)

| 지역 | 선형회귀 RMSE (공통일) | 지속성(persistence) RMSE | 평년값 RMSE |
|---|---:|---:|---:|
| 완도 | **0.26℃** | 0.39℃ | 1.45℃ |
| 여수 | **0.25℃** | 0.36℃ | 1.54℃ |
| 통영 | **0.27℃** | 0.33℃ | 1.71℃ |
| 남해군 | **0.36℃** | 0.40℃ | 1.58℃ |

학습 2021~2023 / 검증 2024~2025(2년을 아예 안 건드리고 아껴둠). 평년값은 1단계 baseline으로만 유지.

### 경보 재현율 — [reports/forecast_alert/summary.csv](../reports/forecast_alert/summary.csv)

국립수산과학원 공식 4조건(28℃ / 3일지속 / 전일대비3~5℃ / 평년대비2~3℃)으로 실측 경보 이력을
재구성한 뒤, 예측값을 같은 기준에 넣어 "모델이 실제로 제때 경보를 냈는가"를 검증.

| 지역 | 전체 판정 일치율 | 실제 위험일 재현율 |
|---|---:|---:|
| 완도 | 94.7% | 80.3% |
| 여수 | 97.5% | 89.8% |
| 통영 | 93.7% | 78.1% |
| 남해군 | 96.3% | 86.7% |

2024년 공식 경보일수(4개 지역): 남해군 34일 · 여수 35일 · 완도 30일 · 통영 20일 — 다른 해는 대부분
한 자릿수. 이 압도적인 2024년 쏠림이 애초에 "왜 평년값이 실패했는지"와 정확히 맞물린다.
→ [reports/alert_reconstruction/](../reports/alert_reconstruction/), 지역별 타임라인 그림 4장 포함.

### 환경변수가 실제로 기여하는지 검증 (숫자 없이 우기지 않았다)

- 기온·풍속 추가: 완도·여수 8.1% 개선, 통영·남해군 2% 미만 — **관측소 거리**(완도5.3km·여수6.5km·
  통영10.8km·남해15.2km)와 순서가 정확히 일치. 우연 아님을 확인.
- 당일 새벽(06시 전) 정보 + 열플럭스 공식 추가: 4개 지역 전부 추가 개선(완도·여수 10.9%/10.8%,
  통영·남해군 2.5%/3.6%), 2024년 9월도 13~17% 개선
- 강수량·일사량: 데이터 신뢰성까지 검증한 뒤 넣었는데 **효과 0.6%대라 최종 미채택** — "안 써봐서
  모른다"가 아니라 "써봤는데 안 됐다"를 직접 확인한 것
- → 상세: [`docs/단기예측_환경변수_검증.md`](단기예측_환경변수_검증.md)

## 3. 2차 멘토링 체크리스트 (1차 멘토링에서 받은 숙제, `docs/멘토링_1차.md` 7절)

| # | 질문 | 상태 | 한 줄 답 |
|---|---|---|---|
| 1 | 회귀 vs 시계열 vs ML | ✅ 답 있음 | 4개 모델 비교, 선형회귀가 전 지역 최고 |
| 2 | 관측값 vs 예보값 입력 | ⚠️ 절반만 | 예보값 수집 모듈은 오늘 작동 확인, 그러나 실제 예측 모델은 아직 관측 lag값으로만 검증 — 둘이 안 이어짐 |
| 3 | ROMS 입력 vs 보정 | ✅ 답 있음(무산) | 3가지 경로(실시간8일제한/직접계산불가/재분석기간안겹침) 다 확인 후 불가 결론 |
| 4 | 경보 온도만 vs 지속시간 | ✅ 답 있음 | 공식기준 자체에 3일 지속 조건 포함, 구현·검증 완료 |
| 5 | 누적 열량(degree-day) 도입 여부 | ❌ 미검토 | 구현 없음 — 그대로 여쭤볼 질문 |
| 6 | ENSO 대리변수 | ❌ 미해결 | 여전히 열린 질문 |
| 7 | 양식방식별 위험도 반영 | ❌ **가장 큰 공백** | 4개 방식 전부 정량 비율 미확정 → 4절 참고 |

## 4. 가장 큰 공백 — 양식방식·어종 추천이 아직 안 붙음

[data/external/farming_methods/farming_method_temp_impact.csv](../data/external/farming_methods/farming_method_temp_impact.csv) 상태:

| 양식방식 | 상태 | 근거 |
|---|---|---|
| 해상 가두리식 | 정량 비율 미확인 | 외부 노출은 정성적으로 설명 가능하나 "100%" 확정 불가 |
| 육상 유수식 | 실측치 있음, 환산식 없음 | 환수율 15~42.6회전/일, 누적폐사율 56.1% (KISTI 보고서) |
| 순환여과식(RAS) | 실측치 있음, 환산식 없음 | 환수율 1회전/일, 누적폐사율 9.7% (KISTI 보고서) |
| 지수식 | 자료 자체 없음 | 확인 중 |

**문제 구조**: "실제 데이터만 쓴다"는 팀 원칙 때문에 환수율·폐사율 같은 실측치는 있어도 이걸
0~100% "수온 영향 비율"로 바꾸는 **변환 공식이 없어서** 못 쓰고 있다. 임의로 만들면 처음에
사용자가 거부했던 "지어낸 숫자"가 그대로 재발한다.

**오늘 여쭤볼 것**: 이 변환 공식(또는 대체 접근)을 어떻게 만들어야 지어낸 숫자가 아닌지, 아니면
정량 비율 없이도 쓸 수 있는 다른 설계(예: 순위/구간 방식)가 있는지.

어종별 적정·치사수온표([data/external/species_conditions/](../data/external/species_conditions/fish_temperature_thresholds.csv))는
이미 있고 공식 경보기준([data/external/warning_criteria/](../data/external/warning_criteria/high_temp_warning_criteria.csv))도
있으니, **양식방식 부분만 풀리면 어종 추천 로직 자체는 바로 구현 가능**한 상태.

## 5. 남은 한계 (숨기지 않고 그대로 말할 것)

- 급등일(전일 대비 큰 폭 상승) 과소예측 편향이 완화만 됐고 완전히 없어지지 않음 — 모델 종류와
  무관한 "정보 구조"의 한계로 확인(XGBoost로도 재현됨)
- 겨울철 오탐: 전일대비/평년대비 조건에 계절 게이트가 없어 기계적으로 주의보가 뜨는 경우 있음
- KHOA 조위관측소(정확한 좌표, 수온·기온·풍속 동시관측) 발견했으나 3개월 샘플뿐, 전체기간 미확보
- 타겟 변수(수온) 자체의 독립 검증은 아직 못함 (기온·풍속·강수는 API로 검증 완료, 수온은 NIFS
  오픈API 인증키 대기 중)
- 발표자료(PPT)는 아직 없음 — 기획서 주차 계획상 이번 주(9/21~9/29)에 만들어야 함
