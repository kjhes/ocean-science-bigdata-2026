# 현재 상태 요약 (압축, 2026-09-16)

## 방향
멘토링 후 피벗: 장기 예측 포기 → **단기(1일) 예측 + 고수온 경보 앱**

## 확정된 것
- **예측모델**: 선형회귀. 입력 = 수온 lag1~3 + 기온(평균/최저/최고) lag1 + 풍속 lag1 + 강수량 lag1
  + **당일 새벽(06시전) 기온·풍속 + 열플럭스공식(풍속×기온-수온차) + 계절(sin/cos)**
- **강수량·일사량(어제값)**: 데이터 검증까지 다 했지만 효과 0.6%대라 최종 미채택
- **성능**: RMSE 완도0.26 여수0.25 통영0.27 남해군0.36 (당일 새벽 정보 추가로 추가 개선)
- **경보기준**: 국립수산과학원 공식 4조건(28도/3일지속/전일대비3~5도/평년대비2~3도)
- **예측→경보 연결**: 재현율 78~90%

## 미해결
- 기상관측소 vs 수온관측소 물리적 거리 — 미확인 (지도로 5분 확인 필요, 사람만 가능)
- 급등일 과소예측 편향은 완전히 안 없어짐 (모델 무관한 구조적 한계, 완화만 됨)
- KHOA 조위관측소(수온·기온·풍속 동시관측, 좌표 명시) 발견했으나 3개월 샘플뿐 —
  전체기간·4개지역 미확보
