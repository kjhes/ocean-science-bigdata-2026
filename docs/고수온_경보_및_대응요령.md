## 1. 고수온 특보 3단계 (표 5-1)

고수온 특보는 **관심 → 주의보 → 경보** 3단계로 구성. 판단 기준은 온도 하나가 아니라
**절대온도 + 지속일수 + 전일 대비 급등 + 평년 대비 이상치**, 네 조건 중 하나라도 걸리면 발령.

| 단계 | 위기경보 색상 | 판단 기준 | 주요 시기 |
|---|---|---|---|
| **관심** | Yellow | 수온 28℃ 도달이 예상되는 7~10일 전후 | 7월 초·중순 |
| **주의보** | Orange | 수온 **28℃ 도달** 예측 해역 <br>**전일 대비 3℃ 이상** 상승 <br>**평년 대비 2℃ 이상** 급격한 변동 | 주로 7~9월 |
| **경보** | Red | 수온 **28℃ 이상 3일 이상** 지속(또는 예상) <br>**전일 대비 5℃ 이상** 상승 <br>**평년 대비 3℃ 이상** 급격한 변동 | 주로 8~9월 |
| 해제 | - | 평년 수온으로 회복 | - |

**주의(용어 헷갈림 방지)**: 표 5-10/5-11의 국가 위기경보 체계에서는 평시(Blue)/주의(Yellow)/
경계(Orange)/심각(Red)/해제 5단계로 부르는데, 이때 "주의(Yellow)"가 위 표의 **"고수온 관심"**,
"경계(Orange)"가 **"고수온 주의보"**, "심각(Red)"가 **"고수온 경보"**에 대응한다. 특보명과
위기경보명이 서로 다른 이름 체계라 발표 자료에서 섞어 쓰지 않도록 주의.

### 우리 분석과의 연결

`anomaly_2024.py`에서 임의로 잡았던 임계값 **28℃가 실제로 공식 주의보 기준과 일치**했다
(우연이었지만 결과적으로 맞음). 그리고 우리가 찾은 **"9월 평년 대비 +2.48℃"**는 정확히
위 표의 **"평년 대비 2~3℃ 이상 급격한 변동"** 조건에 해당 — 2024년 9월은 절대온도 기준(28℃)
뿐 아니라 이 "급변" 기준으로도 경보 대상이었을 가능성이 높다. 다음 단계에서 절대온도 조건과
평년대비 조건을 모두 반영한 경보 로직으로 재구성해야 함.

## 2. 양식방식별 공통 관리요령 (표 5-2 요약)

| 구분 | 관리요령 |
|---|---|
| 공통 | 수과원 홈페이지로 주변 수온 확인, 먹이공급 감소/중단, 조기 출하, 스트레스 최소화, 액화산소·폭기장치로 산소 공급, 피해 시 지자체 즉시 신고 |
| 육상수조식 | 창문개방 등 통풍 확보, 과도한 수온 상승 시 취수 중단 + 액화산소 주입 |
| 해상가두리식 | 선별·망갈이 등 스트레스 작업 금지, (깊은 수심 어장) 저층수 교반(펌핑) 및 가두리 침하 |
| 축제식 | 차광막 설치로 직사광선 차단, 외부수온이 사육수보다 높으면 취수 중단·수차 가동 |

## 3. 어종별 관리요령 (표 5-3~5-7 요약)

| 대상 | 고수온 이전 | 고수온 발생 시 |
|---|---|---|
| 넙치 (육상수조식) | 조기출하·분산, 영양제 공급, 사육수온·용존산소 수시측정(**국립수산과학원 수온정보서비스 앱으로 확인 가능**), 액화산소 상시 공급 | 사료공급 중단, 액화산소 충분 공급, 수온 낮은 지하해수 주입 |
| 조피볼락 (해상가두리) | 조기출하·분산, 가두리 그물 교체·청소, 긴급방류 대비 질병검사 | 사료공급 중단, 액화산소 공급, 저층수 교반 또는 가두리 침하, 차광막(스트레스 감소 목적) |
| 강도다리 (육상수조식) | 조피볼락과 유사 + 안심벨(용존산소 5ppm 이하 감지) 설치 | 사료공급 중단, 지하해수 주입, 냉각기 가동 |
| 전복 (육상수조식) | 환수량 4~6→6~8회전/일로 증가, 액화산소 0.6L/수조(1.2×7.2m)/일, 먹이 50~70%로 감소, 조도 2,000럭스(차광막 1~2겹) | 환수량 6~8회전 유지, 액화산소 0.8~0.9L/일로 증가, 먹이공급 중단, 조도 1,500럭스(차광막 2~3겹) |
| 전복 (가두리) | 조기출하, 먹이(해조류) 공급량 조절 | 먹이 공급 중단, 차광막 설치, 액화산소 공급, 저층수 교반 |
| 바지락 등 바닥식 | 조기 출하로 밀도 조절, 5~6월 저질 15~20cm 경운, 썰물 노출 시 배수관리 | 피해 시 즉시 신고, 폐사체 신속 수거 |

## 4. 고수온 특보 단계별 어업인 조치사항 (표 5-11)

| 단계 | 시기 | 조치 |
|---|---|---|
| 평시 (4~6월) | - | 어린고기 입식밀도 준수, 취약품종 대체어종 입식 검토, 영양제 혼합사료 공급 |
| 관심 (7월) | 주의(Yellow) | 사료공급량 조절(감소), 어류질병 사전예방·치료 완료, 가두리 그물 도색·교체·청소, 산소공급기·냉각시설 점검 |
| 주의보 (7~9월) | 경계(Orange) | 수온·용존산소 자기어장 점검, 사료공급 감소/중단, 액화산소·저층해수공급·산소발생기·에어컴프레서 총력 가동 |
| 경보 (8~9월) | 심각(Red) | 사료공급 중단, 대응장비 총력 가동 유지 |
| 해제 (9월 이후) | - | 양질 사료로 스트레스 완화, 질병관리 강화, 어체 안정화 |

## 5. 남은 과제

- 위 3단계 기준을 `src/analysis/anomaly_2024.py`의 임의 28℃ 임계값 대신 **공식 인용**으로 교체
- "평년 대비 2~3℃ 이상 급변" 조건을 우리 평년값(climatology) 모델과 결합해 **평년대비 경보 로직**까지 구현 (절대온도 조건만으로는 2024년 9월형 사례를 놓칠 수 있음 — 9월 절대온도는 28℃ 근접이었지만 상승폭 자체가 경보 신호였음)
- 어종별 표에서 "노출시간" 조건은 이 문서에 명시되어 있지 않음 (지속일수는 특보 단계 기준에만 있음) → 어종별 치사수온의 시간 조건은 별도 확인 필요
