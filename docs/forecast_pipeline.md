## 3. 결측 확인

| 지역 | 학습 결측일 / 1,461일 | 테스트 결측일 / 365일 | 5년 중 최대 연속 결측 |
|---|---:|---:|---:|
| 완도 | 63 | 17 | 17일 |
| 여수 | 50 | 28 | 30일 |
| 통영 | 3 | 0 | 2일 |
| 남해군 | 43 | 0 | 38일 |

남해군의 2021-08-29~10-05는 38일, 여수의 2023-08-08~09-06은 30일입니다. 이 사이의 실제 수온 변동은 모릅니다. 직선으로 채운 값을 관측 사실처럼 다루지 않습니다. 학습에서는 결측 관측을 제외하고 날짜 위치를 유지합니다. 여름 결측이 많아 학습에 편향이 남을 수 있습니다.

EDA의 3일 규칙은 연구용 표시 규칙이지 공식 보간 기준이 아닙니다. 긴 결측의 일부만 채우지도 않습니다. 변경 후 EDA에는 186개 결측이 남는 것이 정상입니다. 예측 입력에는 원래의 204개 결측을 그대로 보존합니다.

## 4. 모델과 검증을 설명하는 방법

- **평년값 (climatology, 주 모델)**: 각 날짜를 "학습 4년간 같은 시기(±3일) 관측치의 평균"으로 예측합니다. 윤년은 3월 이후를 하루 당겨 통일하고, 12월<->1월도 순환으로 이어 붙입니다. 입력은 날짜뿐이고, 계산은 평균 하나뿐이라 고등학교 수준에서 완전히 설명 가능합니다.
- **Seasonal naive (Baseline)**: 2025-07-01 수온을 2024-07-01 실제 수온으로 예측합니다. 전년 값이 없는 날짜는 예측 불가로 남깁니다. 완도는 전년 8/19~21 결측 때문에 362일만 예측합니다.
- **조화회귀 (비교용)**: 수온 ≈ 평균 + 사인/코사인 계절 곡선들의 합 (+ 선택적인 선형 추세). 계절 모양을 선형회귀로 학습합니다. 평년값과 성능이 거의 같아(아래 표) 주 모델로 채택하지 않고 비교용으로 유지합니다.
- 후보는 곡선 쌍 개수 K=1,2,3,4,6과 추세 유무의 10개입니다. 후보 목록은 2025년 평가 전에 고정했습니다. 2021~2023년 학습, 2024년 관측값 RMSE로 선택합니다. 선택 뒤 2021~2024년을 재학습합니다.
- 선택된 설정: 완도 K=6, 여수 K=2, 통영 K=4, 남해군 K=6. 모든 지역에서 추세 없는 설정이 선택되었습니다. 이는 장기 온난화가 없다는 뜻이 아닙니다.
- 2024-12-31 시점에 다음 365일을 한 번에 예측하는 과거 재현 실험입니다. 2025년 실제 수온을 매일 받아 갱신하지 않습니다. 2026년 이후 운영용 예측은 아직 생성하지 않았습니다.
- **MAE**는 예측과 실제의 절대 차이 평균입니다. MAE 1.21℃이면 평가한 날짜에서 평균 약 1.21℃ 차이입니다. **RMSE**는 차이를 제곱해 평균하고 제곱근을 취하여 큰 오차에 더 민감합니다. 둘 다 낮을수록 좋습니다.

## 5. 실제 2025년 결과

아래는 모든 모델이 함께 예측할 수 있고 실제 관측도 있는 같은 날짜만 비교한 결과입니다. 단위 ℃.

| 지역 | 공통 평가일 | Naive RMSE | 평년값 RMSE | 조화회귀 RMSE | 평년값 RMSE 감소 |
|---|---:|---:|---:|---:|---:|
| 완도 | 345 | 2.1350 | 1.5537 | 1.4746 | 27.2% |
| 여수 | 337 | 2.2882 | 1.5217 | 1.3966 | 33.5% |
| 통영 | 365 | 2.6501 | 1.8014 | 1.7553 | 32.0% |
| 남해군 | 365 | 2.4586 | 1.7436 | 1.7382 | 29.1% |

평년값과 조화회귀의 RMSE 차이는 0.05~0.13℃로, 사실상 같은 계절 곡선입니다. 그래서 더 단순하고 설명하기 쉬운 평년값을 주 모델로 씁니다. 이동평균(moving average)은 연간 계절성이 없어 RMSE 6~12℃로 참고용 하한선입니다.

완도 관측 348일 중 3일은 Naive 참조값이 없어 공통 비교에서 제외됩니다. 결측 날짜에 예측값은 만들지만 실제값을 채워 넣어 평가하지 않습니다. 여수는 실제 관측이 없는 28일을 모든 평가에서 제외합니다.

이 결과는 2025년 한 해에서의 개선이며 통계적 유의성이나 다른 연도 성능을 보장하지 않습니다. **평년값·조화회귀 모두 매끄러운 계절 곡선이라 갑작스러운 수온 변화와 고수온 정점을 놓칩니다** — 정작 고수온 피해 예측이 목적인데 이 부분을 못 맞추는 것이 현재의 핵심 한계입니다. 월별 오차는 `monthly_metrics.csv` 참고. 다음 단계에서 이상값/고수온 구간 성능과 예측 불확실성을 별도로 다룹니다.

## 6. 실행 방법

저장소 루트에서 실행합니다.

```bash
python -m pip install -r requirements-forecast.txt
python src/models/run_forecast.py --regions 완도 --output reports/wando_check
python src/models/run_forecast.py
python -m unittest discover -s tests -v
```

이번 환경에는 최소 의존성이 이미 있어 설치를 추가로 하지 않았습니다. 실제 버전은 `run_metadata.json`에 있습니다. EDA에는 기존 `requirements.txt`의 seaborn 등이 필요하며, 전체 requirements에는 선택 모델인 Prophet/statsmodels와 Jupyter도 포함됩니다.

`--raw-dir`로 같은 폴더 구조의 다른 원자료 디렉터리를 지정할 수 있습니다. `--regions`로 지역을 선택할 수 있습니다. 기본 실행에서는 네 지역 중 자료가 하나라도 없으면 중단합니다. 같은 출력 폴더로 다시 실행하면 해당 결과 파일을 갱신합니다. 일부 지역만 실행할 때는 별도 `--output`을 쓰세요.

## 8. 다음 추천 모델로 연결하는 설계

1. **예측 보강**: 이번 결과를 기준으로 여러 과거 연도 또는 1/7/30일 예측을 추가 검증합니다. 2025년 결과를 보며 반복 튜닝하면 더 이상 독립 테스트가 아니므로, 이후 모델 변경은 새 검증 계획과 구분합니다.
2. **기상변수**: 후보 지점 통영 162 / 여수 168 / 완도 170 / 남해 295는 팀 제공 후보이며 관측소 적합성을 확인합니다. `date, region, variable, value, available_at` 형태로 관리합니다. 2024년 말에 예측하면서 2025년 실제 기온을 넣으면 누수입니다. 단기 예측에 과거 관측의 lag를 쓰거나, 당시 이용 가능했던 기상예보만 사용하고 같은 예측기간의 수온 단독 모델과 비교합니다.
3. **어종 조건**: 기존 8종 CSV에 `source_url, page, life_stage, exposure_duration, threshold_type, verified` 등을 추가합니다. 적정 성장 범위와 스트레스/급성 실험 경계를 구분합니다. 검증되지 않은 수치는 미검증으로 표시합니다.
4. **수온 적합도**: 우선 최적 범위 내 예측일 비율, 검증된 고온 경계 초과일수, 연속 초과일수, 초과 온도 누적 등을 개별 지표로 반환하도록 설계합니다. 임의 합산 점수보다 이유를 먼저 보여줍니다. 일별 평균만으로 순간 최고수온의 피해를 판정하지 않습니다.
5. **양식방식**: 외부 해수 노출/물 교환/능동 수온 조절/종별 사육 가능 여부를 별도 표로 연결합니다. '지수식=항상 중간 위험', 'RAS=항상 낮은 위험'으로 고정하지 않습니다. 시설·운영 정보가 부족하면 조건부 결과를 냅니다. 수온에 0.3을 곱해 RAS 수온을 만드는 계산은 사용하지 않습니다.
6. **최종 출력**: `region + farming_method → species, rank, thermal_metrics, compatibility, reasons, assumptions, source_refs`로 설계합니다. 방식-어종 조합이 실제로 가능한지 먼저 확인합니다. 연구용 가중치를 도입한다면 공식 사실과 다른 설정 파일에 두고 변화에 따른 순위 민감도를 공개합니다.

예측 CSV는 후속 모듈이 읽을 공통 인터페이스입니다. 현재 2025 예측은 성능 검증용이며 실제 다음 해 어종 추천의 미래 예측과 구분합니다. 염분·DO·pH·질병·경제성 정보를 아직 반영하지 않았으므로 완성된 현장 추천 시스템이라고 표현하지 않습니다.
