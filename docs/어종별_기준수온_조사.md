# 어종별 기준 수온 조사 (2026-09-26, 공식 출처만)

앱의 양식장 찾기(국립해양조사원 어장정보)에서 남해안 양식장 대부분이 **패류**(전복·굴 등)로 나왔는데, 앱 기준 수온표
(`data/external/species_conditions/fish_temperature_thresholds.csv`)는 어류 8종뿐이고 **원 출처도 기록돼 있지 않았다**
(팀원 rlqja1322 커밋 `9ca9d9f`, 2026-09-08 — 스크립트 `주요 양식어종별 수온 데이터 코드`에 숫자만 입력, 출처 주석 없음).
그래서 **국립수산과학원이 직접 낸 양식기술 매뉴얼**에서 수치를 다시 찾았다. 언론 기사는 쓰지 않는다.

## 발표용 피해 수치 (국립수산과학원 원문)

「해양수산분야 기후변화 영향 브리핑 북 2025」 https://nifs.go.kr/cmmn/file/climatechange_05.pdf
([사본](reference/국립수산과학원_해양수산분야_기후변화_영향_브리핑북_2025.pdf)):
2011~2024년 양식 재해 피해 4,763억 원 중 **고수온 3,472억 원(73%)**, 2024년 **1,430억 원**(2018년 이후 최대),
굴·피조개·새꼬막·멍게 등도 큰 피해 (15쪽) / 2024년 여수 해역 28℃ 넘는 고수온 37일 (8쪽)

## 참고: 전라남도 문서 (공공기관이지만 수과원 원문 아님)

「고수온 위기경보 단계별 조치사항」(전라남도, https://ofsi.jeonnam.go.kr/bbs/ofsi/48/8813/download.do, docs/reference 사본)의
품종별 '서식(적)수온·한계 수온'(조피볼락 한계 28℃, 참돔 31℃, 넙치 29℃, 강도다리 27℃, 전복 28℃)은 위 수과원 매뉴얼과
일부 다르고(예: 전복 적정 15~18℃ vs 매뉴얼 성장 적수온 20~24℃) 원 출처가 적혀 있지 않아 **참고용**으로만 둔다.

## ✅ 최종 채택 기준 (2026-09-26, 앱 반영)

**통합 규칙**
1. 적정 수온 = 공식 문서의 '성장 적정(적수온)' 범위 → 이 값을 넘으면 앱 '주의'
2. 위험 수온 = 공식 문서가 폐사·섭식 중단·한계와 연결한 가장 낮은 고수온 → 앱은 여기서 0.75℃ 뺀 값부터 '위험'
3. 출처 우선순위: 국립수산과학원 양식기술 매뉴얼 → 없으면 전라남도 관리매뉴얼. **한 품종 안에서는 출처를 섞지 않음**
4. 공식 출처를 못 찾은 품종(농어·방어)은 표에서 제외
