# 평년값 모델의 숨은 전제 — 검증 후 기각

> 1차 멘토링에서 지적받은 내용. 이 프로젝트에서 가장 중요한 전환점이다.

---

## 1. 우리가 세운 줄도 몰랐던 전제

평년값 모델과 그 위의 상승률 보정은 다음 전제 위에 서 있었다.

> **"같은 지역, 같은 시기면, 다른 연도라도 주변 환경이 비슷할 것이다"**

우리는 이것을 가정으로 적은 적이 없다. 당연한 것으로 깔고 진행했다.
가정을 명시하지 않았기 때문에 검증할 생각도 하지 못했다.

**그리고 이 전제는 틀렸다.**

수온에 영향을 주는 요소는 기온, 일사량, 다른 해역으로부터의 해수 유입,
바람, 자연재해 등 매우 많고, 이것들은 해마다 다르다.
날짜가 같다고 해서 이 요소들이 같아지지 않는다.

## 2. 우리 데이터가 보여주는 반례

`docs/2024_이상값_분석.md` 참고.

- 2021년 8월 평균 27.20℃ / 2022년 8월 평균 24.41℃ — 같은 달인데 2.8℃ 차이
- 2024년 9월은 평년보다 2.48℃ 높았고, 같은 해 7월은 1.18℃ 낮았다
- 2021·2022·2025년은 8월이 정점, 2023·2024년은 9월이 정점

같은 달이 해마다 다른 얼굴을 한다. "비슷한 환경"이라 부를 수 없다.

## 3. 따라오는 결과 네 가지

### ① 평년값은 그날의 대표값이 아니다

5년 평균은 서로 환경이 전혀 달랐던 5개 날을 뭉갠 값이다.
**물리적으로 존재한 적 없는 가상의 날**이며, 어떤 실제 연도에도 해당하지 않는다.

### ② 오차가 노이즈가 아니라 체계적이다

- 노이즈라면 → 표본을 늘리면 평균이 되어 사라진다
- **환경 차이라면 → 표본을 아무리 늘려도 사라지지 않는다**

2024년 9월의 +2.48℃는 무작위가 아니라 그해 대기 환경이 달랐던 결과다.

### ③ 우리 진단이 틀려 있었다

우리 판단은 "데이터가 5년밖에 없어서 안 된다"였다.
실제로는 **"20년이어도 안 된다"** 이다.
20년 평균 역시 서로 다른 20개 환경을 뭉갠 값이기 때문이다.

> **데이터 부족 문제가 아니라 모델 설계 문제였다.**

### ④ 델타 기법도 함께 무효

평균의 이동만 다루는 보정인데, 문제는 평균이 아니라 해마다 다른 환경 변동이다.
`docs/장기추세_보정_검토.md` 참고.

## 4. 무엇을 해야 하는가

전제를 뒤집으면 해야 할 일이 나온다.

> **환경이 매년 다르다면, 환경을 직접 측정해서 모델 입력에 넣어야 한다.**

| | 평년값 모델 | 환경 기반 모델 |
|---|---|---|
| 입력 | 날짜 | **현재 환경 실측값** |
| 숨은 가정 | 날짜 같으면 환경 같다 | 없음 |
| 환경 정보 | 없음 | 기온·일사량·강수량·해풍 |
| 성립 여부 | ✗ | ○ |

환경을 실제로 알 수 있는 범위가 며칠이므로, 자연히 **단기 예측**이 된다.
1차 멘토링의 두 지적("단기로 가라", "변수를 추가해라")은
서로 다른 조언이 아니라 **같은 결론의 두 측면**이었다.

## 5. 평년값을 버리지는 않는다

계절성 자체는 실재한다. 태양 고도는 실제로 매년 같다.
평년값 모델은 **비교용 Baseline으로 유지**하고,
새 모델이 이것을 이기는지로 성능을 증명한다.

## 6. 배운 것

모델을 만들 때는 **입력이 무엇을 대신하고 있는지** 먼저 적는다.
평년값 모델에서 "날짜"는 사실 "그 시기의 환경"을 대신하는 값이었다.
그 대체가 성립하는지 확인했어야 했다.
