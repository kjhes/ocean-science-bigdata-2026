# 2024년 고수온 원인 — 초기 추정(라니냐) 철회

> 팀 내부에서 처음 세운 설명이 사실과 달라 기록으로 남긴다.
> 발표 자료에 "라니냐 때문"이라는 표현이 남아 있으면 전부 수정할 것.

---

## 1. 처음 세운 설명

`docs/2024_이상값_분석.md`에서 2024년 9월 고수온을 확인한 뒤,
원인을 **라니냐**로 추정했다.

## 2. 왜 틀렸나

ENSO(엘니뇨·라니냐) 시점이 맞지 않는다.

| 시기 | 실제 상태 |
|---|---|
| 2023~24년 겨울 | 강한 엘니뇨 |
| 2024년 여름 | 엘니뇨 소멸 후 **중립** |
| 2024년 11월까지 | 중립 유지 |
| **2024년 12월** | **라니냐 시작** |

**라니냐는 고수온이 모두 끝난 뒤인 12월에 시작됐다.**
9월 고수온의 원인으로 지목하면 인과가 뒤집힌다.

## 3. 공식 설명

국립수산과학원이 2024년 역대 최고 수온의 원인으로 제시한 것은 다음 세 가지다.

1. 지구온난화 가속화
2. **여름과 가을 사이 한반도 주변에서 지속된 강한 폭염**
3. 적도 인근 저위도로부터의 온난수 유입

2항이 우리가 데이터에서 확인한 "9월까지 여름이 끝나지 않음"과 직접 대응한다.

## 4. 앞으로 쓸 표현

- ✗ "라니냐로 인한 고수온"
- ○ **"엘니뇨 소멸 후 중립 해에 발생한, 폭염 지속형 고수온"**

## 5. 배운 것

원인을 붙일 때 **현상 시점과 원인 시점이 맞는지 먼저 확인한다.**
그럴듯한 기후 용어를 가져다 붙이는 것은 설명이 아니다.

## 6. 참고 — ENSO를 모델에 넣을 수 있나

넣을 수 없다. 우리 데이터는 5년이고 엘니뇨·라니냐 주기는 2~7년이므로
표본에 사이클이 1~2개뿐이다. 이를 설명 변수로 회귀하는 것은 불가능하다.
2차 멘토링에서 대리변수 유무를 확인할 것.
