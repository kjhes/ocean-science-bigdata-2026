## 🔍 진행 중: 양식방식별 수온 영향 비율 (2026-09-08, 실제 데이터만 반영 원칙으로 재작업)

기획서의 3분류(가두리식·유수식·지수식)를 실제 구현에서 4개로 세분화 (지수식과 순환여과식(RAS)을
구분). ~~팀 추정치로 임시 진행~~ → **"실제 데이터 아니면 반영 안 한다" 원칙으로 재작업 중.** 임의로
지어낸 숫자(가정한 회전수, 임의의 능동제어계수 등)는 전부 제외하고, 출처가 있는 것만 남김.

| 양식방식 | 상태 | 근거 |
|---|---|---|
| 해상 가두리식 | ✅ 확정 (100%) | 그물 구조상 물리적 경계 자체가 없음 → 실측자료 불필요, 정의상 자명 |
| 육상 유수식 | 🔶 실측치는 있으나 0~100% 비율 환산식 미정 | 환수율 15~42.6회전/일(평균 26), 누적폐사율 56.1% — KISTI TRKO201900014050, TRKO201900004677(제주 넙치) |
| 순환여과식(RAS) | 🔶 실측치는 있으나 0~100% 비율 환산식 미정 | 환수율 1회전/일(보충수 10%↓), 누적폐사율 9.7% — KISTI TRKO201900014050 |
| 지수식 | ⏳ 데이터 미확보, 확인 중 | 여러 검색어로 조사했으나 정량자료 없음. 사용자가 직접 추가 확인 예정 (가이드라인 문서 등) |

파일: [`data/external/farming_methods/farming_method_temp_impact.csv`](../data/external/farming_methods/farming_method_temp_impact.csv)

**시도했다가 기각한 것**: 가두리 그물 내부 유속이 외부 대비 65% 감소한다는 실측 논문(한국해양환경·에너지학회지,
어류가두리양식장 해수유동 수치모델링)을 찾았으나, 이는 "유속" 측정치라 "수온 차단 정도"의 근거로 쓰기엔
타당하지 않다고 판단해 반영하지 않음 (그물은 열을 막지 않고 물이 그대로 통과하므로 유속과 수온 전달률은
별개 문제).

**남은 문제**: 유수식/RAS의 환수율(회전수)이나 폐사율을 0~100% "수온 영향 비율"로 바꾸는 공식 자체가
아직 없음 — 임의의 변환식을 만들면 다시 "지어낸 숫자"가 되므로, 이 부분도 근거 있는 방식을 찾거나
사용자와 상의해서 정할 것.
