# 장기 추세 보정(델타 기법) — 검토 후 기각

> 결론: **채택하지 않는다.** 보정량이 모델 오차의 1/10이라 효과가 없고,
> 더 근본적으로는 기준선이 되는 평년값 자체가 성립하지 않기 때문이다.

---

## 1. 문제 상황

평년값·조화회귀 모두 입력이 날짜뿐이라 매년 같은 계절 곡선을 반복한다.
"미래 수온 변화율 예측"이 목표인데 변화율이 나오지 않는다.

추세항을 넣어 봤지만 후보 10개(추세 유·무 포함) 중
**네 지역 전부 "추세 없음"이 선택**되었다. 5년으로는 온난화 기울기가 노이즈에 묻힌다.

## 2. 제안했던 방법

20년치 일별 데이터를 직접 확보할 수 없으므로,
**계절 모양은 우리 관측 데이터에서, 장기 추세는 공신력 있는 외부 값에서** 가져온다.

```
예측(날짜 d, 연도 y) = 평년값(d) + 상승률 × (y − 기준연도)
```

기후 분야에서 쓰는 표준 기법이고 **델타 기법(delta method)** 이라 부른다.
장점은 숫자를 지어내지 않는다는 점이다. 양식방식 계수에서 세운
"실제 데이터만 쓴다"는 원칙과도 일관된다.

## 3. 기각 사유 ① — 보정량이 오차에 묻힌다

국립수산과학원: 1968~2024년 57년간 한국 해역 표층 수온 **1.58℃** 상승
(같은 기간 지구 평균 0.74℃) → **연 0.028℃**

| 항목 | 값 |
|---|---:|
| 5년치 보정량 | 0.14℃ |
| 우리 모델 RMSE | 1.5~1.8℃ |

보정량이 오차의 약 1/10이다. 성능표에서 사실상 움직이지 않는다.

## 4. 기각 사유 ② — 문제는 추세가 아니라 연변동

2024년 연평균 표층 수온은 18.74℃로 57년 중 최고였고,
2023년(18.09℃)보다 **0.65℃ 높았다.**

**한 해 만의 변동이 연 추세(0.028℃)의 약 23배다.**

고수온 피해를 만드는 것은 장기 추세가 아니라 그해의 이상값이다.
평균을 조금 올려도 우리가 놓치던 것은 그대로 놓친다.

## 5. 기각 사유 ③ — 기준선 자체가 무효 (근본)

델타 기법은 평년값 위에 상수를 더하는 방식이다.
그런데 평년값 모델은 다음 전제 위에 서 있다.

> "같은 지역, 같은 시기면, 다른 연도라도 주변 환경이 비슷할 것이다"

이 전제가 성립하지 않는다는 것을 확인했다(`docs/평년값_전제_검증.md`).
**망가진 기준선에 상수를 더해도 여전히 망가진 기준선이다.**

## 6. 남는 활용

- 발표에서 **문제 인식의 근거**로 사용한다: "장기 추세는 연 0.028℃인데
  연변동은 0.65℃다. 그래서 장기 예측이 아니라 단기 대응이 필요하다."
- 실제 예측 모델에는 쓰지 않는다.

## 7. 만약 나중에 다시 쓴다면 지킬 것

1. 전국 평균이 아니라 **남해 해역** 상승률을 쓸 것 (해역별로 다름)
2. 연평균이 아니라 **계절별** 상승률이 있으면 그것을 쓸 것
3. 위성 광역해역 값과 우리 연안 관측소는 측정 대상이 다르다는 점 명시
4. 검증이 불가능하므로 "예측"이 아니라 **시나리오**로 제시할 것
5. 먼 미래(2050 등)에 외삽하지 말 것
