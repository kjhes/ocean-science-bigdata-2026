# 남해안 고수온 예보 앱

양식업 종사자를 위한 화면. **양식장 위치·어종 선택 → 7일 예상 수온 → 정상/주의/위험 → 위험 수온 도달 예상일 → 지금 할 일**.

## 양식장 위치별 예보 (2026-09-25)

- 위치 고르기: 빠른 선택(완도·여수·통영·남해) / **내 위치**(휴대폰 GPS) / **지도 누르기** / 관측소 이름 목록
- 남해 수과원 관측소마다 예보 모델이 따로 있고(`src/app/station_models.py`, 2026년 여름 검증 통과한 곳만),
  양식장 위치의 예보는 **주변 관측소 6곳의 예보를 정규 크리깅으로 섞어** 만든다
- 근거(`reports/spatial_experiment`): 관측소 하나를 숨기고 나머지로 맞히기 103곳 × 2023~25 여름에서
  크리깅 오차 1.0℃ vs 최근접 1.12℃(11%↓), 크리깅 불확실성 범위 안에 실제값 96%
- 가장 가까운 관측소가 10km 넘으면 '참고용' 경고, 20km 넘으면 예보를 내지 않음
  (관측소 간 수온 관련성이 약 20km에서 끊김)
- 예상 범위 = √(위치 추정 오차² + 관측소 예보 오차²)
- 지도: Leaflet + OpenStreetMap (인터넷 필요. 연결이 없으면 지도만 숨기고 나머지는 동작)

## 여는 법

- `app/index.html`을 더블클릭하면 브라우저에서 바로 열린다 (서버 필요 없음).
- 휴대폰 크기 확인: 브라우저 개발자도구(F12) → 기기 모드.
- 주소로 특정 화면 바로 열기 (발표·공유용):
  `index.html?place=완도&species=넙치&date=2026-08-01` 또는 `index.html?lat=34.40&lon=126.70`
  - `place`: 완도 / 여수 / 통영 / 남해
  - `species`: 어종 이름 앞부분 (넙치, 조피볼락, 참돔 …)
  - `date`: 지난 예보 기준일 (올해 6월 1일부터). 빼면 최신 예보

## 예보 갱신 (매일 아침 한 번)

```
app\update_forecast.bat            (더블클릭)
또는  python src/app/build_forecast.py
```

1. 수과원 실시간 관측 조회로 최근 40일 수온, 기상청 ASOS로 최근 45일 기상을 받음 (`.env`의 `DATA_GO_KR_API_KEY` 필요)
2. 지역별로 수온·기상이 모두 있는 마지막 날(보통 어제)을 기준일로 7일 예보
3. `app/data/forecast.js` 저장 → 화면이 이 파일을 읽음

인터넷 없이 가진 자료로만 다시 만들 때: `python src/app/build_forecast.py --no-refresh`
모델을 다시 학습할 때(새 연도 자료가 쌓였을 때): `python src/app/final_model.py`

## 판정 규칙

| 표시 | 조건 (어종별) |
|---|---|
| 위험 | 예상 수온 ≥ 위험 수온 − 0.75℃ (관측된 현재 수온은 위험 수온 이상일 때만) |
| 주의 | 적정 수온 상한보다 높음 |
| 정상 | 그 외 |

- 위험 수온·적정 수온: `data/external/species_conditions/fish_temperature_thresholds.csv`
  (팀이 국립수산과학원 자료로 정리한 표 — 수치별 원문 확인 필요)
- 0.75℃ 여유폭: 모델이 급상승을 작게 예측하는 경향이 있어 일찍 알리도록 보정.
  2026년 여름 검증에서 28℃ 도달의 71%를 미리 잡음(도달일 오차 평균 1.7일, 경보의 약 50%가 실제 도달)

## 예보 모델 (자세한 근거는 `PROGRESS.md` 2026-09-24)

- 지역별 선형회귀: 수온 1~3일 전 값 + 전날·새벽 기상 + 3·7·14일 기상 흐름 + 계절, 전날 수온 20℃ 이상이면 고수온 구간 전용 모델
- 하루씩 굴려 7일 예측. 예보일 이후 날씨는 예보일 값이 이어진다고 가정
- 학습: 수과원 같은 관측소 2012~2025 여름(완도 군외는 2020~)
- 2026년 여름(학습에 안 쓴 기간) 확인: 다음 날 ±1℃ 이내 98%, 3일 뒤 82%, 7일 뒤 65%

## 디자인 원칙

- 대상이 중장년층: 본문 18px, 버튼 높이 56px, 글자 대비 4.5:1 이상
- 상태는 색만으로 구분하지 않고 항상 글자와 함께 (색각이상·야외 햇빛 고려)
- 각진 모서리, 그림자·그라데이션 없음, 선과 여백으로 구분 (공공서비스 KRDS 계열)
- 4일 뒤부터는 '참고용'으로 표시 — 정확도가 떨어지는 구간을 숨기지 않음
